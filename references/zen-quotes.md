# zen-quotes · 金句库（按主题分组）

> **何时读我**：需要给 deck 配一句权威引语、或写文案想借书里原话时。逐字引用，标书页码与出处人。中日共通格言可直接作中式 deck 文案。

## 简约 / 减法
- 「极致的高深即简单。」——列奥纳多·达·芬奇（书页2 引言扉页）
- 「凡事需要尽可能地简化，但不要简单过了头。」——阿尔伯特·爱因斯坦（书页116）
- 「简约就是运用最少的手段获得最大的效果。」——川名幸一（书页119）
- 「设计师必须遵循『见隐』的原则，因为日本人相信，若将事物的一切都表现出来则有损观众的利益。」——川名幸一（书页119）
- 「超越浓墨重彩与繁复的装饰，返璞归真，简单得体，这才是美的最高境界，正所谓简单就是美。」——詹姆斯 & 珊朵拉·克劳力《侘寂》（书页120）
- 「如果艺术家能以简单的手法直接表露事物的本质，那么他的创作意涵将被大幅提升。」——史考特·麦克劳德（书页124）
- 「简约就是力量。」（书页126）
- 「禅意美学所倡导的简约之美使我们更易关注事物的本质，而不是其他无关紧要的事物。」——约翰·戴多·卢里《创意心法》（书页140）
- 「传递信息，需抓主弃次。过于繁琐，只会令人生恶。简洁方能让人思路清晰。」——《无为而活》理查德·鲍威尔（书页58）
- 「细节问题会浪费人的生命，要从简!」——亨利·戴维·梭罗（书页112/设计篇题记）
- 「多余的话语，哪怕只是一个词，也只会把本已饱和的大脑压垮。」——西塞罗（书页250）
- 「有用则留，无用则删，绝不要手下留情!」（书页107，谈卢卡斯剪辑）
- 「我花了毕生的时间去学习什么是不应该演奏的。」——迪兹·吉莱斯皮（书页251）
- 本章要点：「简约很重要……但简约不等于简单，也不等于容易完成……平衡是其中的关键。」（书页129）

- 「拥有一个好点子的最佳办法就是获取大量的点子。」——莱纳斯·鲍林（书页96）

- 「初学者可包容万物，而老练者则反之。」——铃木俊隆（书页34）
- 「孩子天生就是艺术家，问题是他们长大后如何保持他们的艺术家天分。」——巴勃罗·毕加索（书页31）
- 「对于软件的功能和使用技巧，问题不是你学会了多少，而是你可以忽略和忘却多少。」（书页9）

## 自然 / 独处 / 投入
- 「他人激发我们，知识哺育我们，实践提升我们；但我们仍需独处，在独处的时间里，冥思静想，进而寻求新解。」——艾丝特·布赫兹（书页57）
- 「独处有着积极的作用，学会独处才能激发创造力。不要惧怕独处。」——罗洛·梅（书页60）
- 「止水而可辨自身。」——道家谚语（书页59）
- 「除非把心境调整到无心或完全自然的状态，否则任何习得的技艺都会显得不自然而且无力。」——铃木大拙（书页218）
- 「海水在不停地流动，月亮却保持着它的宁静。大脑要对不同的情形做出反应，同时保持内心的平静。」——铃木大拙（书页218、236）
- 「只有当你真正沉浸于音乐之中，人们才能真切地听见你的演奏，并为之动容。」——布兰达·乌兰德《如果你想写作》（书页219）
- 「这就好比做演说，投入才是关键，而不是技巧。」（书页287）
- 「如果你有真情实意，即便用鞋带也能演奏音乐。」——约翰·克特兰（书页251）
- 「掌握你的乐器，掌握你的音乐，然后忘记其他所有不愉快的事情，你要做的只是全身心地演奏。」——查理·帕克（书页250）

## 设计 / 视觉 / 交流
- 「（被传递的）那些具有神奇魔力的正是非语言的部分，它们隐藏在演说者的肢体动作、讲话节奏、面部表情、目光交流之中。」——Chris Anderson（书页12）
- 「演说时单有逻辑是不够的，因为交流就是情感的转移。」——Seth Godin（书页36）
- 「所谓交流，是使他人采纳你的观点……如果只是以文档形式展示一组事实和数据，建议还是取消会议，给每人一份报告得了。」——Seth Godin（书页36）
- 「没有对比就没有效果。」——保尔·兰德（书页174）
- 「不要让幻灯片上的任何东西像是被随意摆放上去的，而要让各元素就好像被无形的线条贯穿在一起。」（书页177）
- 「最先映入眼帘的是什么？其次又是什么？……什么最吸引你呢？」——Robin Williams（书页177）
- 「幻灯片的画面越吸引人，观众就越容易记住。更重要的是，他们也会记住设计者。」——保尔·雅顿（书页184）
- 「设计者的目标并不是把幻灯片设计得『好看和炫目』，而是清晰。」（书页187）
- 「人们误以为『空』即一无所有，它实则蕴藏着无限可能。」——铃木大拙（书页176）
- 「建立属于自己的画面风格，让其变得独一无二和具有可辨性。」——奥森·威尔斯（书页172）
- 「忘记那些 PowerPoint 和数据吧，只有通过讲述故事才能深深打动观众。」——《哈佛商业评论》（书页84）
- 「为了激发他们的积极性，必须打动他们……打动他们就要使用故事。」——罗伯特·麦基（书页84–85）
- 「不论演说前后，绝不要把幻灯片打印出来发给观众，那样就意味着演说的失败……如果只用幻灯片就够了，还要演说者干什么？」——大卫·罗斯（书页68）
- 「电脑是个白痴。（你和你的想法以及你的观众才是重要的。）」——彼得·德鲁克（书页74）
- 「有了创意，没有机器也能办事……你尽可在沙地上用一根细棍绘出创意。」——阿伦·凯（书页49）
- 「我认为，电脑是人类有史以来最伟大的工具。有了它，人类的心智好比骑上了一部单车，可以任意驰骋。」——史蒂夫·乔布斯（书页46、62）

## 勇气 / 精进 / 征程
- 「未来将属于那些拥有与众不同思维的人。」——丹尼尔·平克（书页14）
- 「放手去吧！不要顾虑重重！要像狮子一样勇猛，做个海盗!」——布兰达·尤兰（书页37）
- 「在这一时刻，这关键的时刻，我们要有所贡献，那是我们的职责……只是为了贡献出我们的某些东西。」——本杰明·赞德（书页225）
- 「如果你用『半个屁股坐着』的方式演奏音乐的话，其他人将无法抗拒你的力量，这种力量将会激励他们用心演绎。」——本杰明·赞德（书页227）
- 「看他们的眼睛。如果他们的眼睛闪着光，你就做到了……如果观众目光无神，你就要问自己：为什么他们的眼神呆滞呢？」——本杰明·赞德（书页278）
- 「一旦忘记对事物产生好奇，我们便失去了最珍贵的东西。在当今，好奇心是帮助我们成长最重要的品质。」——茂木健一郎（书页259）
- 「许多人都想成为一名优秀的演说者，并希望寻得成功的捷径。但这种捷径是不存在的。」（书页285）
- 「学无止境，关键看你是否拥有一双发现它们的慧眼。」（书页288）
- 「你要相信自己，不要依赖微软或苹果公司，自己的选择自己做。」（书页288）
- 「结论就是根本没有结论，有的只是下一步该怎么走，而且将由你自己选择……演说的征途才刚刚开始。」（书页289）
- 「千里之行，始于足下。」——老子（结束语引言页）
- 「我们终将变成自己所想的样子。」——佛陀（书页282）
