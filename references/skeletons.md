# 骨架库 · 大师构图（第二根轴）

> 2026-08-07 建立，PT 提出「借鉴建筑/美术大师」后，经五张实证样张确立。
> **材质换皮肤，骨架换版式。** 材质（32 母版）管"用什么做的"，骨架管"画面怎么被切分、字放在哪块面上"。
> 样张与配方正本：`~/projects/ppt-master/projects/ppt-master-styles/`

## 一条铁律：骨架写构图指令，不写风格名

prompt 里写「扎哈风格」→ AI 每次给的东西都不一样。
写「两道最宽褶皱之间留一条宽、平、哑光的平静带，所有文字只住在这条带里，绝不趴在曲面上」→ 一次成图。
**五张样张全部一次成图**，靠的就是这一条。这与全图四硬规则同源：AI 稳定复现靠可执行的构图描述。

## 五个骨架 × 各自解决的版式需求

| 骨架 | 大师 | 用在什么页 | 构图一句话 | 文字住在哪 |
|---|---|---|---|---|
| **网格** | 密斯 | 清单 / 矩阵 / 对照表 | 不等宽分跨（如 2:3:2），钢梁分隔 | 每格一项，**字不跨梁** |
| **光带** | 安藤 | 章节 / 金句 / 一页一义 | 一道斜光带切过大墙，右三分之一留黑 | **只住在光里**（最平最亮的面） |
| **流线** | 扎哈 | 封面 / 冲击 / 愿景 | 连续曲面折成分层地形 | **两道最宽褶皱之间的平静带**，绝不趴曲面 |
| **色域** | 罗斯科 | 情绪转折 / 金句 / 章节 | 三块巨大色域上下叠，边界羽化不画线 | **浮在最大那块中央**，四周全空 |
| **对峙** | 路易·康 | 对比 / 二元 / before-after | 两个等重体量对望，中间一道竖光井 | 左右各一组，**同基线对齐**；光井即分隔线，不画线不用箭头 |

**罗斯科的特殊价值**：色域里物理上放不下第二个焦点——它把"一页一职能"从纪律变成约束，最省心。
**康的特殊价值**：以前对比页只能拿密斯两列硬凑，那是"并列"不是"对峙"；康天生是对峙。

## 骨架由页面职能自动派（不问用户）

| 页面职能 | 派哪个骨架 |
|---|---|
| 封面 / 惊吓 / 冲击 | 流线（扎哈） |
| 章节页 / 金句 / 情绪转折 | 光带（安藤）或 色域（罗斯科） |
| 清单 / 矩阵 / 六件事这类 | 网格（密斯） |
| 对比 / 二元 / 前后 | 对峙（康） |
| 证据页（要摆出真东西） | 网格（密斯）——证据要能扫读 |

用户只说"做个 PPT"时，**不要问他要哪个骨架**，按上表派。

## 两轴相乘：怎么把大师材质换成我们的

大师自带的材质是**结构性材质**——混凝土是安藤那道光能成立的前提（平整哑光才切得出硬边），
钢是密斯梁能做那么细的原因。我们那 32 个是**表面材质**（肌理与笔触，不决定构图）。

**判据：签名是"形"就能换材质；签名本身就是材质就不能拆。**

| 大师 | 签名 | 能否换材质 |
|---|---|---|
| 密斯 | 比例与网格（形） | ✅ 能 |
| 扎哈 | 流线曲面（形） | ✅ 能 |
| 罗斯科 | 色域并置（形） | ✅ 能，且与"染"类材质同源，最合 |
| 康 | 体量对峙（形） | ✅ 能 |
| 安藤 | **光是形，混凝土是材质** | ⚠️ 部分——光打在和纸/夯土上成立；**打在丝绸上不成立**（反光吃掉光影，骨架塌） |
| 高迪 | 签名本身就是马赛克 | ❌ 不可拆，只能整体当预设 |

### 相乘的 prompt 结构（实证有效，X1 一次成图）

```
SURFACE:  材质配方（管所有笔触与介质）
          ⚠️ 必须显式禁掉大师原材质：NO concrete / NO photographic / NO 3D
          否则 AI 会把混凝土偷偷带回来
SKELETON: 纯几何构图（管版式，不出现任何材质词）
END:      用 SURFACE 的材质，表现 SKELETON 的构图
```

### 实证：X1「水墨 × 安藤」
骨架认得出是安藤（斜光带/留黑/点阵），材质完全是水墨（宣纸/晕染/书法/朱砂印），零照片感。
**并且出现了两个父本都没有的东西**：墨在光影交界处自然晕开——安藤的边是硬的，水墨化开了。
→ **材质会改变骨架的性格，但不改变骨架的结构。** 所以 32 材质 × N 骨架 = 32N 种**性格**，不是贴图变体。

## 失败模式（配之前先想）

- **材质吃掉骨架的可读性**：安藤 × 丝绸（反光毁光影）。配不成就直说"这两个不能配"，别硬出糊图。
- **满构图材质**：波斯地毯、草间弥生的圆点——**全幅无焦点、不留白，字没地方站**，与幻灯片需求相反。
  草间是图案不是骨架，只能进材质列且需大量留白。

## 待补（下一批候选）

- **序列推进**：贝聿铭（沿轴线展开的几何体量，有进深前后）
- **多层同现**：隈研吾（木格栅层叠，层间半透，前后都在）
- 明确不做：柯布西耶（与密斯功能重叠）、葛饰北斋（动势与扎哈部分重叠）
