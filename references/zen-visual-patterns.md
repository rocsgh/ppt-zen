# zen-visual-patterns · 视觉模式库（全包最核心资产）

> **何时读我**：给 你的图像生成工具 写 COMPOSITION、或想给某页找一个「成熟的构图套路」时。每条=模式名 + 画面 + 为什么有效 + 适用场景 + 出图要点（可直接拼进 prompt）。逐条保留书页码。素材主要来自 A4/A5，兼收 A1/A2/A3。

书中图几乎全部来自 iStockphoto.com；「改后」图表统一规律见开头。

## ★ 通用「图表去噪」变换（信噪比六连，书页135–137）
**一条规则套所有 Excel 图表**：改后 = **深色/纯净底 + 单色柱/条 + 数据标签直接标在柱顶/柱内 + 一个强调色（红）高亮唯一关键项 + 去掉图片背景/3D/边框/图例**；标题改成**结论句**（「2012 年销售了 5000 多辆自行车」而非「自行车销量」）。
- 饼图 → **水平条形图降序**更一目了然（书页135，作者特别点名）。
- 具体做法：自行车销量（末柱红）、有机农田（3D 饼→水平条 66/23/7/2/1/1）、手机上网率（韩国条红）、犯罪数（美国红条最长）、发电站类型（核 14.8% 红）、男子吸烟率（日本红）、便当销量（纯白无边框极简表、数字右对齐）、OECD 肥胖率（首末两项红 + 右侧标「10×」点出倍数）。
- **出图要点**：`dark/clean background, single-color bars, data labels on bars, ONE red highlight bar, conclusion-style title, no 3D no legend no border`。

### 模式：满版图 + 文字压角
- **画面**（书页171、23、42）：一张占满画布的高质量情绪照，**文字退到图片的暗部/留白半区**（左上、右下、底部皆可，非居中）。例：老人半脸右侧+左上红标题；黄昏剪影+左上「告别过去的艺术。」；樱花特写+底部文字。
- **为什么有效**：一图一义、图承载情绪、留白给文字呼吸；文字不与主体抢位。
- **适用**：开场设问、抒情过渡、引用名言、章节主张。凡有一张情绪强烈的照片就满版铺开。
- **出图要点**：`full-bleed emotive photo, minimal text placed in the dark/empty quadrant (not centered), title aligned along a third line`。

### 模式：唯一焦点单色高亮
- **画面**（书页136、137、190）：整张灰/单色的柱条或人偶阵列里，**只有一条/一个用红色（或对比色）跳出**（韩国 89% 红条、蜿蜒小路上一个红衣小人立于黑色田野）。
- **为什么有效**：对比制造「一个清晰焦点」，观众零思考知道看哪。
- **适用**：数据页强调某一项、人群中突出「你/我们」。
- **出图要点**：`everything desaturated/gray, exactly one element in vivid red as the focal point`。

### 模式：视线/运动方向引导
- **画面**（书页156、180–181、197、199）：画面里人物侧脸/动物的**目光、身体、飞行方向朝向文字或数据**——冈仓天心照片目光朝引语；肯尼迪侧脸朝引文（观众先看脸、视线自然转到文字）；鸬鹚鸟嘴当指针、海鸥飞行方向指向文字；猴子摆荡方向朝文字；人物面朝饼图而非朝外。
- **为什么有效**：卡尔·萨根——大脑对人脸/朝向高度敏感；位于所视方向的文字获更多注意力（James Breeze 眼动研究）。
- **适用**：引用配肖像、人物+数据、动物题材。
- **出图要点**：`subject's gaze/face/motion points toward the headline; never facing out of frame`。★可验收。禁忌：面孔朝画外把观众目光带离（书页181）。

### 模式：before → after 减噪（通用减法）
- **画面**（书页180–183，减噪四组+图表两组+要点列表两组）：把模板/Excel 带来的杂乱页——①**统一背景色（白/单色）**、②满版化图片、③文字嵌入图（把小配图调成满版背景，「把图片背景色调成白色即可」融入）、④删三维/边框/图例/剪贴画、⑤留一个要点。例：锤子工具箱散图→统一白底；花哨纸飞机封面→平静栈桥暮色照；小金鱼配框→整幅金鱼满版背景文字嵌入；弧形模板 1/3 空间浪费→猫王模仿者满版。
- **为什么有效**：前后景对比增强→文字数据可读性大增；删国家/选重点/统一背景/单色高亮。
- **适用**：清洗一切从模板/Excel 带来的杂乱页。
- **出图要点**：`unify background to one flat color, make the key image full-bleed, embed text into the image, remove clipart/3D/borders/legend`。

### 模式：一信息 N 种做法（同一数据五版，书页148–149）
- **画面**：「日本 72% 兼职是女性」——(坏)蓝渐变模板+剪贴画折线；(普通)黑底大字+卡通小人；(坏)3D 饼图；(较好)要点+小照片；(好)**全屏真实日本女性照+叠加大字 72%**；最终采用=咖啡馆用平板的女性生活照+「72% 的兼职是女性」，整套统一用日本照片达成视觉统一。
- **为什么有效**：示范同一信息从「模板剪贴画」到「满版真实照+大数字」的升级阶梯；真实照片+大数字最有力。
- **适用**：单一数据要做成一页海报；教学「怎样一步步改好」。
- **出图要点**：`one real full-bleed photo + one oversized number, culturally-consistent imagery across the set`。（提醒：没提「日本」的版本离开讲者就无意义——Ⓑ deck 要把语境写进画面。）

### 模式：高桥法大字（Takahashi Method）
- **画面**（书页206–207，案例10）：**纯白底 + 超大黑色文字，每张只有寥寥数字**（一两个词/短语，报纸标题式），字号占满整屏，无任何图片；一场用超百张、极快翻页。
- **为什么有效**：「用要点列表/语句，观众会去读而错过你讲的话」；极短标题→观众瞬间看懂就回到听讲。作者按语：不是最佳、不适用所有场合，但远优于枯燥要点式。
- **适用**：极简、快节奏、无图素材时的应急；强调「大字短词优于要点列表」。
- **出图要点**：`pure white background, one or two huge black words filling the frame, headline-style, no images`。

### 模式：黑底发光网格（母题重复变奏）
- **画面**（书页15、143，六大能力）：近纯黑背景，**2×3 六宫格**，每格=顶部大号词（设计/故事/整合/移情/幽默/意义）+ 中间一枚**橙红发光灯泡 monoline icon**（灯泡内形随主题变）+ 底部小字反差注脚。
- **为什么有效**：暗底让发光元素跳出；同一视觉母题重复变奏；一张图承载六页文字列表（要点列表→图标网格）。
- **适用**：能力/维度/模块的并列展示，替代要点清单。
- **出图要点**：`near-black background, 2×3 grid, each cell one glowing monoline icon + one word, unified icon language`。

### 模式：质感底统一（和纸/牛皮纸，重复原则的极致）
- **画面**：①**和纸 washi 暖棕做旧纸纹**做全套背景（竹子案例，书页188，16:9），叠满版自然照+汉字大字+引语；②**做旧牛皮纸/砂纸棕底 + 白色手写涂鸦 grunge 大字**（Think Like a Designer 案例，书页191，纯文字无照片，13 条编号页）。
- **为什么有效**：一套自定义质感背景=最强的「重复」，整套统一又有手工温度（侘寂）；重点条放大+对话气泡做对比。
- **适用**：主题演讲、文化质感统一、清单式纯文字演讲。
- **出图要点**：`aged washi/kraft-paper texture as unified background, hand-written grunge title, consistent across the whole deck`。

### 模式：回形针红便签（统一签名元素，书页175–176）
- **画面**：每张都是不同的满版实景照，统一叠加一个「**回形针夹住的红色便签**」承载标题；红便签的**大小和位置每张不同**但风格一致。
- **为什么有效**：统一视觉签名又不呆板（重复+根据内容改大小位置）；显专业。
- **适用**：系列演讲/一本书/一个项目需要统一签名元素时。
- **出图要点**：`different full-bleed photo each slide, one recurring red sticky-note (clipped) holding the title, note size/position varies`。

### 模式：便签纸/胶带质感承载文字（书页150、157、159）
- **画面**：满版照片上贴一张**略倾斜的白色便签纸/透明胶带**放引文（学无止境/差异/苏斯博士引言）。
- **为什么有效**：便签把文字与背景**有效区分**、增深度；略倾斜增趣又不分散。
- **适用**：满版照片上放引言/短句而背景太花时。
- **出图要点**：`slightly-tilted white sticky-note / taped paper holding the quote over a full-bleed photo`。

### 模式：同载体时间对比（书页146、203）
- **画面**：**同一个视觉载体在不同时间点并置**——干涸湖床「然后(蓝湖)|现在(龟裂)」；便当「之前|之后」；人类进化图末尾加个胖子「27 years」；**14 张同一美国地图逐年变红**（1985/95/2001/2010）揭示肥胖剧增；LCHF 餐 vs 高糖餐的两条血糖曲线。
- **为什么有效**：控制变量只变时间，趋势一目了然、极具说服力（阿尔·戈尔《难以忽视的真相》大量用今昔对比）。
- **适用**：趋势、增长/恶化、前后效果、亲身实验证据。
- **出图要点**：`same visual container repeated across time points, only the data changes, side-by-side or animated sequence`。

### 模式：惊人数字 + 悬念翻转（书页194–195，Shift Happens）
- **画面**：满版视觉，**一页一个惊人数字/事实**，大字重点数字高亮（「如果你在中国是百万里挑一，那也有 1300 个人和你一样」；「38」；怀表「During this presentation… 60/244/351 babies born」）；**悬念翻转**页：「POP QUIZ Name this country」→翻页揭晓「England… in 1900」+国旗。
- **为什么有效**：大脑对新奇/出人意料敏感（乔布斯 13 条第 10）；数字给参照系才有冲击。
- **适用**：震撼型数据演讲、社会趋势/宏观议题。
- **出图要点**：`one shocking number per slide, oversized highlighted figure, full-bleed visual; set up a question then reveal on next slide`。

### 模式：引用配图（大图出血 + 目光朝文字，书页154–157）
- **画面**：整幅黄昏冲浪照叠引文（比小配图+页脚「更耳目一新」）；引文作者**照片目光朝向引语**；长引语分两张、字号大、**关键词红色**（乔布斯 connecting-the-dots 两张，底部五颗鹅卵石呼应）。
- **为什么有效**：大图>引文旁小图；作者肖像目光把注意力带向引文。
- **适用**：名言金句页、名人引用。
- **出图要点**：`full-bleed photo + overlaid quote, keyword in red, author portrait gazing toward the quote text`。

### 模式：表格 → 三柱极简（数据减负，书页72、110–116 图表减噪）
- **画面**：一张 30 国肥胖率表格+密集柱（Excel 直接粘）=坏 → **黑底红柱三国对比**（Japan 3.2 / France 9.5 / USA 32.2）+结论式标题「Obesity: an American epidemic?」=好，其余细节放讲义；医疗支出堆叠柱只选六国+顶部数值标注。
- **为什么有效**：摘最有用的一点、删其余；前后景对比增强可读性。
- **适用**：把 Excel 原始大表改造成一句话演说图。
- **出图要点**：`pick 2–3 key data points, dark background, single red highlight, conclusion title; dump the rest to handout`。

### 模式：一个概念一个图标（简洁支撑式，书页219–220 Inbox Zero + 案例11）
- **画面**：一个概念配一枚单一 iStock 图标+关键词（Delete/Delegate/Respond/Defer/Do 五动作各一张彩色图标大字；「Make Sandwiches」配三明治）。
- **为什么有效**：方法论/流程拆成一步一图标，简洁支撑演讲。
- **适用**：方法论、流程、生产力工具讲解。
- **出图要点**：`one concept = one clean icon + a keyword, one per slide`。

## 对齐+就近 before/after：标题/封面页（书页178–179）
「演说设计的原则」四版演进：居中散列五行(反例，像五个不相干部分)→分组+对比→**居右对齐**(优于居中，「演说设计」特大、「原则」小字)→黑底版红点与底部红 logo 遥相呼应。**结论：居右>居中 + 分组 + 颜色呼应**。适用封面/标题/讲者介绍页。

## 弱对比 vs 强对比三组（书页174）
标题页：蓝渐变陷进背景 →纯黑底「没有」黑白大字+「对比」红色粗体。折线图/条形图同理：深底+清晰坐标+关键数据标注+单项红高亮。示范「用颜色和粗细制造唯一焦点」。

## 三等分应用四页（书页170）
主体元素落三分线/着力点，留白提供呼吸：疾走上班族裁切用三分法、喝咖啡的男人在左三分、米饭碗在左上、红苏打杯在右三分。

## 纸芝居五启示（图叙事原则，书页88）
1 画面要大且清晰可辨。 2 图画元素应填满画面。 3 图画起画龙点睛而非仅装饰。 4 仔细精简细节。 5 使画面与叙述具参与性。→ 全图页出图的底层准则。

## 第7章 11 套完整案例（讲者+整套风格，速查）
1. **竹子的启迪**（Reynolds，TEDxTokyo）：和纸质感+满版自然照+汉字大字+引语，16:9。
2. **像设计师一样思考**（Reynolds）：牛皮纸底+白色 grunge 大字，13 条编号，纯文字。
3. **独树一帜**（Reynolds，金融品牌）：黑底+大幅满版照+极简白字，金句驱动（「You are **not** a commodity」not 红高亮）。
4. **Shift Happens**（Jeff Brenman，2007 金奖）：满版信息化数据页，一页一惊人数字+悬念翻转。
5. **可持续粮食实验室**（Chris Landry，铜奖）：黑底纪实照+白字，**有意多加文字**（供在线自足浏览）。
6. **芳烃化学**（Aisyah Saad，大学教授）：深红黑底+分子结构图，**步步推导**讲苯结构历史——证明理科/学术也能图文并茂、逼学生听而非抄。
7. **动物**（Sangeeta Kumar，PETA）：满版动物照+极简文字，**回避图表和晦涩引语**、用震撼图片直击情感。
8. **肥胖症**（Andreas Eenfeldt，瑞典医生，身高 **6 英尺 8 英寸**）：数据+权威引语+**亲身实验血糖图**三重支撑；14 张地图逐年变红。准备法=白板+报事贴风暴→筛选分类→创建→排序。
9. **我的独立宣言**（Pam Slim）：真人情绪照+第一人称短句宣言，建立共鸣。
10. **高桥流简报法**（高桥征义）：见上「高桥法大字」。
11. **Inbox Zero**（Merlin Mann，Google Tech Talk）：一概念一图标简洁支撑式。
> ★案例计数订正：标题虽称「九套」，实际 **11 套**（9 主体 + 高桥法 + Inbox Zero）。
