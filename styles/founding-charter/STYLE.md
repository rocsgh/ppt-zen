# Founding Charter

**A document that expects to be signed.** Parchment, iron-gall ink, engrossed calligraphy,
a wax seal — the material carries authority before a single word is read. Built for charters,
compacts, cap tables, founding agreements: anything where the deck *is* the ceremony.

*The signature move: end the deck with a signing page — signature lines, printed names,
a wax seal. Non-Latin text renders as brush-serif calligraphy that harmonizes with the
charter aesthetic (validated in production with Chinese).*
