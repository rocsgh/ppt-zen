Reproduce it

The exact prompts live in examples/ (both editions) — material + device + verbatim text + the anti-garble tail, then assembled with one command.

cd examples/relayboard-portolan          # or examples/relayboard (dark edition)
cp ../../.env.example .env               # your image model key
python3 gen.py                           # 10 pages -> slides/
python3 ../../scripts/assemble_pptx.py slides deck.pptx
